# Banca - Comprehensive Banking Application

**Banca** is a comprehensive banking application designed to enhance user experience by providing essential features such as account management, transaction tracking, money transfer functionalities, and loan applications. This project aims to create a secure and user-friendly platform that meets the diverse needs of modern banking customers.

## Features
- **Account Management**: Users can view, manage, and update their bank account details.
- **Transaction Tracking**: Keep track of all financial transactions with a real-time transaction history.
- **Money Transfers**: Secure transfer of funds between accounts with real-time updates.
- **Loan Applications**: Users can apply for loans through an intuitive interface.
- **Responsive Design**: Optimized for both desktop and mobile devices.

## Technologies Used
- **HTML**: The structure of the application is built with HTML.
- **SCSS**: SCSS is used for styling, providing an efficient way to manage CSS and add styling features.
- **Firebase**: Utilized for backend services, including **authentication**, **real-time database**, and **user management**.
- **Parcel**: Used as a bundler for compiling and bundling the project efficiently.
